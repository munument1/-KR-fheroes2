# fheroes2

**fheroes2**는 히어로즈 오브 마이트 앤 매직 II(Heroes of Might and Magic II) 게임 엔진을 재구현한 프로젝트입니다.

처음부터 새롭게 작성된 이 오픈 소스 멀티플랫폼 프로젝트는 원작을 충실하게 재현하는 동시에 게임 플레이, 그래픽, 게임 로직을 크게 개선하는 것을 목표로 합니다.
고해상도 그래픽 지원, 향상된 AI, 수많은 버그 수정과 사용자 인터페이스 개선 등을 통해 가장 중독성 강한 턴제 전략 게임 중 하나였던 원작에 새로운 생명을 불어넣고 있습니다.

프로젝트에서 적용한 모든 변경 사항과 개선 내용은 [**이 페이지**](docs/GAME_IMPROVEMENTS.md)에서 확인할 수 있습니다.

## 저작권

원작 게임과 해당 리소스에 대한 모든 권리는 과거 The 3DO Company에 있었으며, 현재는 Ubisoft로 이전되었습니다.
이 프로젝트는 원작 게임의 어떠한 불법 사용도 권장하거나 지원하지 않습니다.
[**GOG**](https://www.gog.com) 또는 [**Ubisoft Store**](https://store.ubi.com)에서 원작 게임을 정식으로 구매할 것을 강력히 권장합니다.
또는 무료 데모 버전을 다운로드해 사용할 수도 있습니다. 자세한 내용은 [**설치 안내서**](docs/INSTALL.md)를 참고하세요.
